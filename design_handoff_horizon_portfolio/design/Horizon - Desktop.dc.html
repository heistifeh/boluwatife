Front end to system: wallet funding, all the way down

One real feature from Insta-Delivery, traced through every layer he touches. When it breaks, he can find it and fix it at any one of them.

  1. 01 Screen — "Fund wallet"

    Amount sheet, method picker, and the confirmation state the user actually trusts.

  2. 02 Component — React Native + TypeScript

    Typed form state, validation, an optimistic pending row, error and retry paths.

  3. 03 State — Redux slice, Supabase session

    Balance is one source of truth, shared by checkout, transfers and vendor earnings.

  4. 04 API — Node service

    Initialise funding, verify the provider webhook, write the ledger entry once — idempotently.

    POST /wallet/fund → { reference }
    POST /wallet/webhook → verify(sig) → ledger.insert(once)
  5. 05 Data — Postgres

    wallets, ledger_entries, referrals — the referral feature released behind a flag, then widened.
