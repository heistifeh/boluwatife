Wallet funding, all the way down

One real feature from Insta-Delivery, traced through every layer he touches.

  1. 01 · Screen: "Fund wallet"

    Amount sheet, method picker, and the confirmation state the user actually trusts.

  2. 02 · Component: React Native

    Typed form state, validation, an optimistic pending row, error and retry paths.

  3. 03 · State: Redux, Supabase

    Balance is one source of truth, shared by checkout, transfers and vendor earnings.

  4. 04 · API: Node service

    Initialise funding, verify the provider webhook, write the ledger entry once.

    POST /wallet/fund → { reference }
    POST /wallet/webhook → ledger.insert(once)
  5. 05 · Data: Postgres

    wallets, ledger_entries, referrals. The referral feature shipped behind a flag, then widened.
