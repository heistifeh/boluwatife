Art direction, staging and motion spec

One warm horizon glow, low in every frame, with real product screens staged in front of it. Deep near-black everywhere else. Every dramatic beat is attached to a real product, a real number or a real outcome. Built as the desktop site and mobile compositions.

Note: the reference screenshot described in the brief did not come through with this message, so the glow was built from the brief's written description (sunrise/eclipse arc, warm amber to deep orange-red, screens staged in its light). The two motion layers, stacked without compounding

The ambient base is a single fixed, position:fixed pair of blurred linear-gradient sheets behind everything (z-index:0, page content at 1) — the only blurred elements in the whole design, and the only thing that animates without scroll. Because they live in one fixed, contain:strict layer, their 42s/61s transform loops are composited once and never repaint per section. The scroll-tied staging glow stays blur-free radial gradients inside each section, driven on one shared rAF. Ambient touches transform only; staging touches transform and opacity — so the two never write the same property on the same element.

/* layer 1 — ambient, everywhere, always, scroll-independent */
[data-ambient]      position:fixed; inset:0; z-index:0; contain:strict;
  sheet A           linear-gradient(116deg, gold-1 @0.10 → gold-2 @0.06)
                    blur(44px); animation: ambientA 42s ease-in-out infinite;
  sheet B           linear-gradient(94deg,  gold-2 @0.075 → gold-1 @0.05)
                    blur(64px); animation: ambientB 61s ease-in-out infinite;

/* layer 2 — staging, per section, scroll-tied, blur-free */
[data-glow="1.3"]   opacity = base × (0.7 + 0.3·nearness)
                    transform = translate3d(0, −q·44px, 0) scale(1 + 0.07·nearness)

@media (prefers-reduced-motion: reduce) {
  [data-ambient] > * { animation: none; }   /* sheets hold their pose */
  /* staging glow stays at its base opacity, no scroll drift */
}

2 · The glow

Three stacked ellipses, all anchored to the bottom of the section and centred, all pure CSS radial gradients — no filter: blur(), no canvas. Blur-free gradients are what keep this at 60fps on a mid-range phone. Within a section, hue never changes — only scale and opacity do; between sections the brightest stop swaps to that project's tint token while the haze and the edge stay on --glow-2 and --ink.

3 · Screen collage staging

A fan, not a grid. Every screen is absolutely positioned inside a stage by percentage of stage width, with left + translateX(-50%), so the whole composition scales with the viewport. Depth is read three ways at once: width, distance off the baseline, and brightness. Adjacent screens always overlap — no visible gap between neighbours.

5 · Motion

One signature move, repeated with intent. Cards, text and nav never move; nothing hovers or lifts.

Glow drift — the continuous thread

Per section, q = clamp(((scrollMid − sectionTop) / sectionHeight − 0.5) × 2, −1, 1). Then translateY = −q × 44px, scale = 1 + (1 − |q|) × 0.07, opacity = base × (0.7 + (1 − |q|) × 0.3). The glow is brightest and largest when its section is centred, and sinks as it leaves. Only transform and opacity — never layout properties. Driven by one rAF loop with a dirty flag set on scroll, section geometry cached on resize, and an IntersectionObserver (±25% margin) so off-screen glows cost nothing.

Screens settling into light

Each screen enters from translateY(34px) scale(0.96) opacity 0 to rest on transform 840ms cubic-bezier(0.16,0.72,0.24,1), opacity 520ms ease-out. Depth-staggered by 95ms in data-order: anchor first, then mid, then far. Weighted and settling, never bouncy. Fires once per screen on intersection (hero settles on load); will-change is cleared 900ms after arrival so no layer is promoted for longer than it needs.

Front end to system — the one functional use

Layer progress lp = clamp((p − i × 0.13) / 0.2, 0, 1) drives row opacity 0.40 → 1.00, and past lp > 0.5 the row's dot switches to --glow-1 with a warm halo. The connector is a 2px vertical gradient of --glow-1 fading at both ends. Light walks the sequence as you read it.

Reduced motion

prefers-reduced-motion: reduce (or the Still mode tweak) drops the rAF loop entirely: every glow sits at its base scale and opacity, every screen is at rest and fully opaque, all five stack layers are lit, and smooth scrolling is off. The still page is the same composition, just held — nothing is hidden behind an animation.

6 · Quality floor

  • Screenshots ship at 520px wide, JPEG q86 (~40–70KB each) — the source uploads were 1206×2622 PNGs, roughly 12MB of decoded bitmap each, which is the single biggest threat to the 60fps floor on a glow-heavy page. Anchor screens render at ~270 CSS px, so 520 keeps a 2× buffer.
  • No blur() or backdrop-filter anywhere except the fixed nav bar. Gradients only.
  • All copy lives in the DOM. Nothing is painted only in canvas.
  • Focus ring is 2px #E8D2A6 plus a 6px --ink halo, so it stays visible over the brightest part of the glow as well as flat black.
  • Body text is full-opacity ink (--body / --paper), never alpha-muted over the glow. Minimum 4.5:1 everywhere, and the dashed "in development" and "placeholder" flags read as chrome, not as decoration.
  • Tweaks on the page: glow intensity (0.5–1.4, scales every section's glow at once), Still mode, and the Voltra concept panel toggle.
